Format CV apa yang didukung?

PDF dan DOCX, maksimal 5MB. Gunakan PDF teks (bukan hasil scan/foto) agar parser NLP bisa membaca isinya.

Apa beda mode Match vs Career?

CV vs Job membandingkan CV dengan satu Job Description spesifik. Career hanya butuh CV, lalu merekomendasikan 3 jalur karier terbaik dari profil skill Anda.

Bagaimana skor dihitung?

Skor 0–100% dari cosine similarity embedding SentenceTransformer + klasifikasi TF-IDF/LR. Level: LOW (<40), MEDIUM (40–60), HIGH (60–80), EXCELLENT (>80).

Kenapa upload gagal / "Analysis failed"?
  • Pastikan file PDF/DOCX ≤ 5MB dan tidak corrupt.
  • Mode Match wajib mengisi Job Description.
  • Coba logout lalu login ulang bila sesi kedaluwarsa.
Tidak bisa login?
  • Cek username & password (case-sensitive).
  • Belum punya akun? Daftar di sini.
  • Lupa password? Reset via: manage.py shell → u.set_password(...).
Apakah data CV saya aman?

File hanya diproses sementara lalu dihapus setelah analisis. Hasil tersimpan privat per akun. Detail: Kebijakan Privasi.
